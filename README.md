
# Offline POS — المرحلة الثانية

نظام POS عربي Offline-First مبني بـ Flutter وSQLite.

## ما تم إنجازه
- Dashboard / لوحة تحكم.
- POS / شاشة الكاشير.
- Cart / سلة المشتريات.
- إدارة المنتجات CRUD.
- تعديل المخزون مع تسجيل Stock Movement.
- بحث بالاسم والباركود.
- ماسح باركود بالكاميرا.
- تنفيذ الفاتورة داخل SQLite Transaction.
- خصم المخزون تلقائياً بعد البيع.
- حفظ سعر التكلفة وقت البيع.
- حساب الربح لكل سطر ولكل فاتورة.
- شاشة المبيعات والفواتير.
- تقارير اليوم / الشهر.
- أكثر المنتجات مبيعاً.
- تنبيه انخفاض المخزون.
- Responsive للموبايل والتابلت.

## التشغيل

```bash
flutter pub get
flutter run
```
